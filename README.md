# mc-schematics

Voice-bridge schematic platform data source.

- catalog.json - index (category / size / blocks / preview and file path)
- schematics/*.schem - Minecraft 1.20.1 Sponge format
- previews/*.png - isometric 3D preview

Sources: Piscescup/MC-Java-Schematics, Mindstormman06/litematics (converted to 1.20.1).
